Install

Two minutes to a funded agent.

1 · Create the wallet

Node 20 or newer. The kit installs straight from this site (npx allot-kit once it is on npm). The key is written to ~/.allot/agent.json (mode 600). It never leaves your machine.

npm i -g https://allot.fun/downloads/allot-kit-0.1.0.tgz
allot init
allot policy perTxUsd 10      # cap per action
allot policy dailyUsd 50      # cap per 24 h
allot policy owner <your wallet>   # where revoke --sweep sends funds

Fund it: USDC is enough to pay x402 APIs (the seller pays the network fee). Add a little SOL to anchor the registry and to trade. On localnet, allot usdc 10 mints test USDC. Testing? ALLOT_CLUSTER=devnet (the default) or localnet.

Claude Desktop

Settings → Developer → Edit Config, then add:

{

    "allot": { "command": "npx", "args": ["-y", "https://allot.fun/downloads/allot-kit-0.1.0.tgz", "mcp"] }
  }
}

Restart Claude. Ask: "What's my Allot budget?"

ChatGPT

ChatGPT talks to remote MCP servers over HTTPS. Run the server and expose it with a tunnel:

allot serve                      # http://localhost:4340
cloudflared tunnel --url http://localhost:4340
allot config chatgpt             # prints the secret MCP path

In ChatGPT: Settings → Apps & Connectors → Advanced → Developer mode, then Create. Paste https://<tunnel>/mcp/<key>, authentication none. The key in the path is the secret; the owner controls (allotment, revoke) are never reachable through the tunnel.

CLI

allot status                 address, balance, allotment left
allot pay <url>              pay an x402 endpoint
allot buy BONK 0.05          quote + swap 0.05 SOL of BONK
allot sell BONK 1000000
allot history                the registry
allot revoke --sweep         stop the agent, send funds home

Trading modes

Prices always come from Jupiter on mainnet. Off mainnet, a swap is simulated: it fills at the fresh Jupiter quote into a paper portfolio and is written to the registry as simulated. Real swaps need ALLOT_CLUSTER=mainnet and ALLOT_LIVE=1.

What's enforced, and where

RuleEnforced by
Per action, per 24 h, total capsAllot, from the registry itself, before signing
Hosts it may payAllot, before the first byte is paid
Price floor of a tradeAllot re-quote, then Jupiter on chain
Freeze-authority tokens refusedAllot, from Jupiter's audit data
RevocationAllot, on the next call; --sweep moves funds on chain
Registry integrityHash chain + ed25519 + Merkle root in an SPL Memo

The caps run on your machine, next to the key. A model can't change them (no tool does), but anyone with shell access to the machine can. Keep the allotment small and the wallet a hot wallet.
