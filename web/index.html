The difference

Other kits let the agent pay. This one lets it trade.

Ask for a trade in plain words. The agent resolves the token, refuses honeypots, prices it on Jupiter, checks your caps and executes. No click per trade inside the allotment, no key leaving your machine, and a public line in the registry for every swap.

How it works

Four parts, one wallet.

01 · Allotment

Caps the agent can't raise

Per action, per 24 hours, in total, plus an expiry, a token list and a pay list. Set by you from the CLI or the dashboard. No MCP tool can touch it.

02 · Pay

x402, natively

An endpoint answers 402 with a price. The agent signs a transfer for exactly that amount, the seller settles it, the answer comes back. Hosts you didn't allow are refused.

03 · Trade

Any Solana token

Ticker, name or mint. Freeze authority on means refused. It re-prices before signing and aborts if the market moved past the floor it showed.

04 · Registry

Public and checkable

Every action is hash-chained, signed by the agent key and rolled into a Merkle root posted in an SPL Memo. Anyone can check an entry on /verify.

Tools your agent gets

Six tools. That's the kit.

ToolWhat it does
allot_walletIts address, balance, holdings and trading mode.
allot_budgetCaps, what's used, what's left. It checks before spending.
allot_payFetches a URL and pays its x402 price from the wallet.
allot_quotePrices a buy or sell of any token on Jupiter. Nothing moves.
allot_swapExecutes the quote, under the floor it showed.
allot_historyThe public registry: every payment and trade.
Kill switch

Revoke in one command.

The next tool call fails, whatever the agent was doing. Add --sweep and the balance goes back to your own wallet. The revocation is itself an entry in the registry.

$ allot revoke --sweep
{ "revoked": true, "swept": "4xQ…9Lm" }

agent → allot_swap
